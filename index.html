Playing with the camera

  • Sit about an arm's length back so both hands fit the frame, with light in front of you, not behind.
  • Move freely — it's silent. With no pinch held, only your pluck hand's index fingertip selects: it pre-lights the string nearest it, but crossing strings makes no sound. Your other fingers never trigger anything, so you can travel across the whole harp to get into position without playing a note.
  • Pinch to play. Hold a thumb-to-index pinch on the pluck hand and the pinch point becomes a pick (the amber puck on screen). While you pinch, sweeping that pick across a string plucks it — faster crossing = louder pluck. Release the pinch and you're silent again instantly, free to reposition.
  • The badge at the stage's top-left always shows which state you're in: Moving — silent, or Pinching — playing. A string has to be re-crossed to sound again — no machine-gun retriggering.
  • Harmony hand: hold an open palm for major, make a fist for minor. The strings retune the moment the new shape settles. Pinch on this hand sustains — notes ring longer while you hold it — and raising or lowering it brightens or darkens the tone.
  • Chord mode (Play toggle below): crossing a string with the pinch held plays the whole chord built on that string's degree instead of one note.
  • Mouse / touch: moving without pressing is silent selection, exactly like the un-pinched hand; press and drag is the pinch — crossings fire while pressed.

Why it stays in key

Every string is a scale degree, never a chromatic note, so a wild strum is an arpeggio in key instead of a mess. Pentatonic is the default — five safe notes per octave, the layout projects like AetherPlay use so any combination still sounds good.

Switch to Full scale for all seven degrees, and flip Major/Minor to hear the same strings retune — in minor, the third, sixth and seventh degrees drop, exactly as diatonic harmony says they should.

How the pluck is detected

Adapted from Gesture Synth's engineering write-up: a hit is a plucking point's path segment crossing the string — not just pointing at it — with velocity taken from crossing speed, an 80 ms cooldown per string, and a ~100 ms pose-stability rule before a hand shape commits, so chords and modes don't flicker.

The plucking point is gated by a pinch clutch: un-pinched, the index fingertip only selects and nothing it crosses can sound; pinched, the thumb–index midpoint is the one and only pick. The strings themselves are fixed in place — a pluck only sets a string vibrating around its home position, capped well inside the gap to its neighbours, so strings never drag, wander, or overlap.

The string sound is a Karplus-Strong plucked-string model (the family behind Tone.js's PluckSynth), generated note by note in your browser.
